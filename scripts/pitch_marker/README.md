# Разметка поля вручную (pitch_marker)

Быстрый редактор опор: выбрать точку на схеме → кликнуть её на кадре. 8–12 кадров на
игру, около 30–60 секунд на кадр.

## Запуск

1. Кадры полного размера каждые 15 с (одна машина RunPod, ~1,5 ч на все 24 игры, ~1 $):

       python scripts/pitch_frames_all.py            # все игры прогона
       python scripts/pitch_frames_all.py --only bsht_baldariki,dolon

2. Редактор для одной игры (поле: lower — №1, №2; upper — №3, если ширина 19,0):

       python scripts/pitch_marker/server.py results/pitch/<slug>/frames_<slug>_full \
              results/pitch/<slug>/manual --pitch lower --port 8770

   Открыть http://localhost:8770.

## Как размечать

- Точка на схеме → клик на кадре. Номер точки можно нажать на клавиатуре.
- Нужны точки с **разных линий**: углы штрафной (3–6, 14–17) — самые надёжные; стойки
  ворот (7, 8, 18, 19) стоят чуть за линией, их — только если больше нечего.
- Колесо — масштаб, правая кнопка или пробел+тянуть — сдвиг, лупа у курсора.
- После 4 точек рисуется вся разметка: если она не ложится на линии — точка с красным
  номером стоит не там, её можно перетащить. `Z` — отменить, `Delete` — убрать выбранную.
- Кадр без поля — `X` (пропустить). `D`/`Enter` — следующий кадр, `A` — предыдущий.
- Сохраняется само в `manual/frame_t<сек>.json`, зелёные кнопки — размеченные кадры.

## Дальше

Опоры отдаются в `pitch_track.py` через `--anchor manual/frame_t*.json` (свои кадры
той же игры), затем `to_metres.py`, `match_stats.py --metres ... --win 1.5`.
