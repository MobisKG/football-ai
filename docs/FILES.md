# Где что лежит

Всё нужное для работы собрано в этой папке. Больших видео здесь нет: они
остаются на мак мини в `~/football-ai/videos/`, 12 ГБ на семь матчей.

## Что смотреть

| Путь | Что это |
|---|---|
| `viewer_clip5.html` | просмотрщик событий, открывать в браузере |
| `crops/clip5/` | 1023 фотографии игроков по трекам, нужны просмотрщику |
| `crops/track13918/` | отдельная галерея одного игрока, номер 6 |

Просмотрщик просит указать файл клипа. Клип лежит в `~/Downloads/football/`
и весит 226 МБ, поэтому в проект не скопирован.

## Данные

| Файл в `results/` | Что внутри |
|---|---|
| `clip5w_events.json` | 89 событий клипа: время, тип, команда, участники |
| `clip5w_pos.json` | позиции, команды, номера, вратари по клипу |
| `clip5_numbers.json` | номера, форма и роль по 419 трекам, первый проход |
| `clip5_roles.json` | переспрос про роль центрального человека, второй проход |
| `clip5_ball_wasb.json` | траектория мяча по клипу |
| `match_ball_wasb.json` | траектория мяча по всему матчу, 140 501 кадр |
| `full_pos.json`, `full_stats.txt` | старый прогон матча, команды в нём сломаны |
| `train_7matches.csv` | кривая обучения модели на семи матчах |

## Веса

| Файл | Что это |
|---|---|
| `weights/best_7matches.pt` | нынешняя модель, yolo11l, семь матчей |
| `weights/best_2matches.pt` | прежняя, yolo11s, два матча |

Веса WASB для мяча не хранятся: они скачиваются на арендованную машину прямо
с Google Drive авторов, ссылка в `scripts/wasb_video.py`.

## Скрипты

`scripts/` — всё, что запускается на ноутбуке и на арендованной машине.
`mac/` — то, что живёт на мак мини: подготовка кадров, выгрузка на Диск,
удаление арендованной машины.

## Эталон

`truth/qE8fVwIRQxA_clip5_0-57.json` — первая минута клипа, размеченная глазами.
Главный измеритель качества.
