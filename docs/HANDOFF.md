# Как продолжить работу в новой переписке

Скопируй текст ниже и отправь первым сообщением.

---

Продолжаем проект автоматического анализа футбольных матчей. Проект лежит в
`/Users/doni/Documents/football`.

Прочитай сначала `STATE.md`, там текущее состояние и что запущено прямо сейчас.
Затем `README.md` для общей картины, `docs/VIDEOS.md` со списком матчей,
`docs/scripts.md` с описанием скриптов и ловушек, `docs/FINDINGS.md` с
замеренными цифрами и выводами.

Рабочая машина: мак мини `doni@100.103.159.76`, каталог `~/football-ai`.
Подключение по ssh. Если Tailscale попросит заново войти, дай мне ссылку.

GPU арендуется на RunPod, ключ лежит в `.env` в корне проекта как `KEY=`.
Поднимать машину можно через REST API `https://rest.runpod.io/v1/pods`.
Обязательно удаляй машину после завершения работы, чтобы не тратить деньги.

Держи нагрузку на маках умеренной, долгое время выполнения приемлемо.
