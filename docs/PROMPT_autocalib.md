## Что считать успехом

1. Для каждой игры автоматические опоры не реже чем каждые 15 с (кадры уже есть).
2. Проверка на отложенных кадрах: часть моих опор не показывать модели, на них ошибка
   проекции ориентиров < 0,7 м в среднем, < 1,5 м максимум. Отдельно — наложение
   разметки (`pitch_check.py`) на 8 случайных моментах каждой игры, лист картинок в
   `results/pitch/<игра>/check_auto.jpg`; я смотрю их глазами утром.
3. Пробег и скорость правдоподобны: 40–70 м/мин у игроков с ≥5 мин на поле, максимальная
   скорость медиана 16–24 км/ч, единичные до 30; дрожание у стоящих ≤ 1 м/с.
4. Загружено на сайт только то, что прошло 2 и 3; остальное — в отчёт с причиной.
5. Обученная модель (если будет) сохранена в `weights/`, способ запуска описан, чтобы
   следующее видео с этих площадок считалось одной командой.

## Направления (проверить и выбрать по цифрам, не по вкусу)

- Детектор ориентиров поля по моим опорам: keypoint/heatmap-модель (например, YOLO-pose
  на 19 ключевых точках или небольшая U-Net с тепловыми картами), сильная аугментация
  (сдвиг, масштаб, поворот, цвет, размытие) — размеченных кадров пока мало (~30, будет
  ~190), поэтому обязательно отложенная выборка по играм, а не по кадрам.
- Классика: белые линии (top-hat + Hough/LSD) → сопоставление с планом при известном
  грубом положении (от соседней опоры или детектора) → уточнение матрицы по линиям.
- Гибрид: детектор даёт грубую матрицу, линии её уточняют; между кадрами (15 с) —
  ничего не протягивать, каждый кадр сам по себе; поток — только для интерполяции
  внутри 15 с при переводе позиций в метры.
- Синтетика: рендер плана поля с случайной камерой поверх реальных кадров для
  предобучения, если реальных данных не хватит.
- Готовые модели разметки футбольного поля (SoccerNet calibration, TVCalib и т. п.):
  проверить на наших кадрах, дообучить на моих опорах.

## Известные ловушки

- `pgrep -f`/`pkill -f` находят собственную команду запуска — шаблоны через `[p]attern`,
  очистку и запуск делать отдельными ssh-вызовами.
- На машинах RunPod 96 ядер: `OPENBLAS_NUM_THREADS=16 OMP_NUM_THREADS=16`, иначе
  UMAP/KMeans падают без traceback.
- YouTube не пускает часть адресов RunPod: видео качать на машине, при отказе — с другой
  машины, целостность mp4 проверять по последнему пакету (`run_video.sh`), не по заголовку.
- Qwen называет форму двух команд одним цветом — к разметке не относится, но
  `team_from_kit.py --use-clusters` / `--kit-map` есть на этот случай.
