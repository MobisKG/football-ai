# Скорости и пробег по пакетному прогону: почему не посчитаны

Проверено ночью 15.09.2026 по кадрам с машин (`frames/`, `sheet_first_frames.jpg`)
и карточкам матчей на сайте.

## Что мешает

1. **Арена другая.** Все игры прогона сыграны на «Душанбинке», а замеры рулеткой
   в `docs/PITCH.md` сделаны для площадок «Динамо».

   | Поле «Душанбинки» | Игр в прогоне |
   |---|---|
   | №3 | 11 |
   | №2 | 7 (и Gz United vs Real 91) |
   | №1 | 5 |
   | неизвестно | 2 безымянных видео |

2. **Камера с рук, не закреплена.** Оператор стоит на высокой трибуне у средней
   линии и всё время поворачивает камеру: между кадрами одной игры смещение сотни
   пикселей. Одной привязки на поле мало, нужна привязка на каждый кадр
   (`pitch_track.py`) с опорами у обоих ворот — как для клипа 5.

## Что нужно, чтобы посчитать

- Размеры трёх полей «Душанбинки»: ширина, длина, ворота, штрафная — как в `docs/PITCH.md`.
- Для каждого поля — опорные кадры с разметкой у ближних и дальних ворот
  (оператор, похоже, снимает каждое поле с одной точки, поэтому опоры можно
  переиспользовать между играми одного поля; это надо проверить на двух играх).
- Видео на машине для протягивания привязки по кадрам (скачивается за минуты).
- Проверка глазами (`pitch_check.py`) хотя бы на одной игре каждого поля до
  загрузки на сайт.

Позиции всех игр (`<игра>/pos_final.json`) уже есть: пересчитывать на видеокарте
не нужно, только привязка и `to_metres.py` + `match_stats.py --metres`.
